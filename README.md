# 🚀 Next.js 14 & Supabase Full-Stack Application Suite

A modern full-stack web application featuring a **Tech Forum** and an integrated **Task Management System**, built with Next.js 14, Supabase, Tailwind CSS, and TypeScript.

## ✨ Key Features

### 💬 Tech Forum
- **Authentication**: Email/Password login and sign-up powered by Supabase Auth.
- **Q&A System**: Create posts, answer questions, and view author profiles.
- **Real-time Search**: Instant title and content filtering on the client side.
- **User Dashboard**: Personal profile page to view and manage published posts.

### 📋 Task Manager
- **Task Tracking**: Full CRUD capability with dynamic status updates (`To Do` ➔ `In Progress` ➔ `Done`).
- **Deadlines & Priorities**: Assign completion dates and priority levels (`Low`, `Medium`, `High`).
- **Data Isolation**: Row Level Security (RLS) ensuring strict per-user data privacy.

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Database & Auth**: [Supabase](https://supabase.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Deployment**: [Vercel](https://vercel.com/)
